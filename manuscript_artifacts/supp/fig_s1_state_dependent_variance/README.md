# Supplementary Figure: state-dependent variance

Output: `supp_state_dependent_variance_vs_budget.pdf` and a matching PNG.

The normalized CSV columns are `panel`, `method`, `measurements`, `variance`,
and `selection`. Molecular rows are obtained from the exact setting-resolved
Born variances. Sparse/dense rows are arithmetic means over the same five
instances used in Main Figure 5. GPD rows are accepted only when `selection`
is `depth-L=4 stabilizer-calibrated GPD prefix`. LiH rows are not configured.

The legend is placed above the six panels and every x-axis reads “The number of
measurements”.
