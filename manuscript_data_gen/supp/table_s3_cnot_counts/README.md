# Supplementary table: projected executed CNOT counts

Input: `resource_chart_summary.csv`. The generated matrix reports total
executed CNOT counts at projected total RMSE `0.01 Ha` for the same frozen
measurement designs used by the required-measurement table.

This CNOT table is restricted to SRDD, FC-IMA, OGM, SG and Derand, as listed
in `artifact.json`. It does not include native-iSWAP GPD/AGPD. For these
displayed methods the existing `two_qubit_gate_budget_to_error_0p01` input
contains only CNOTs (zero for the product-Pauli methods).

When extending the table to a method with iSWAP gates, use separate CNOT
and native iSWAP columns. Never relabel their combined two-qubit count as
CNOTs. Updated resource summaries provide
`cnot_gate_budget_to_error_0p01` and `iswap_gate_budget_to_error_0p01`.
Frozen input CSVs and existing TeX outputs are not regenerated by the
native-gate code/documentation update.
