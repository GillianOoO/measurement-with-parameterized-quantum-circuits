# Measurement with parameterized quantum circuits

Research code for fixed-number-of-measurements expectation-value estimation with two
rotated-diagonal decompositions:

- **GPD** — Greedy Projection Decomposition with sequential full-diagonal
  projections generated by a fixed periodic-iSWAP circuit family.
- **SRDD** — Shallow Rotated-Density Decomposition for real spin-restricted
  electronic Hamiltonians, together with its Pauli-complete residual wrapper
  for general explicitly specified Hamiltonians.

For a total shot budget `T`, each interface returns the selected approximate
Hamiltonian, its executable rotated-diagonal settings, an exact integer shot
allocation, and approximation and sampling error quantities. The optional
reference state is used only for post-selection evaluation.

dependency.

```powershell

.\.venv\Scripts\Activate.ps1
```


[`manuscript_data_gen`](manuscript_data_gen/README.md). Install their optional


```powershell

python manuscript_data_gen/build_all.py --output build/manuscript
```

## Python API

```python
from mpqc_measurement import GPDConfig, SRDDConfig, run_gpd, run_srdd

gpd = run_gpd(
    "examples/h2_pauli.json",
    shots=100,
    config=GPDConfig(
        paper_depth=1,
        max_terms=2,
        steps=5,
        calibrate=False,
    ),
    output="results/gpd-smoke",
)

srdd = run_srdd(
    "examples/h2_pauli.json",
    shots=100,
    config=SRDDConfig(calibrate=False),
    output="results/srdd-smoke",
)

print(gpd.approximate_hamiltonian)
print(srdd.error.state_independent_rmse_bound)
```

The small two-qubit example has fewer than the ten candidates required by the
frozen calibration protocol, so the smoke example explicitly uses the
uncalibrated proxy. The rigorous state-independent error bound is still
reported.

An optional normalized state vector may be supplied in the input or with
`state=...`. It never affects fragment construction, candidate selection, or
shot allocation.

```python
result = run_gpd(H, shots=1000, state=psi, config=GPDConfig())
print(result.error.state_bias)
print(result.error.state_sampling_variance)
print(result.error.state_rmse)
```

```powershell
mpqc-measure validate examples/h2_pauli.json

  --no-calibrate --output results/gpd-smoke
```

GPD uses the paper artifact precision (`float32/complex64` during nonlinear

`--x64` for the explicit double-precision extension.

## Input formats

### Dense matrix

- `.npy`: a finite Hermitian array of shape `(2**n, 2**n)`.
- `.npz`: canonical key `hamiltonian`; compatibility key `H` is also accepted.
  Optional key: `state`.

The qubit order is `q0` most significant in the computational-basis index.

### Pauli JSON

```json
{
  "schema_version": 1,
  "n_qubits": 2,
  "qubit_order": "q0-most-significant",
  "terms": [
    {"pauli": "II", "coefficient": -0.20},
    {"pauli": "ZI", "coefficient": 0.40},
    {"pauli": "IZ", "coefficient": -0.30},
    {"pauli": "XX", "coefficient": 0.15}
  ]
}
```

A coefficient may be a real number or `[real, imaginary]`. Hermitian Pauli
input requires the imaginary component to vanish numerically. The schema
version and qubit order are validated rather than inferred.

### Electronic-integral NPZ for the SRDD core

```text
constant            scalar float
one_body            float64 [m,m]
two_body_chemist    float64 [m,m,m,m]
n_electrons         scalar even integer
state               optional complex128 [2**(2m)]
```

The tensor convention is

```text
H = constant I
  + sum_pq h[p,q] E[p,q]
  + 1/2 sum_pqrs G[p,q,r,s] (E[p,q] E[r,s] - delta[q,r] E[p,s]),
E[p,q] = sum_sigma a[p,sigma]^dagger a[q,sigma].
```

The input must be real, finite, and symmetric in chemist order. The backend
uses Jordan–Wigner mapping, blocked spin ordering (all alpha modes followed by
all beta modes), and a closed-shell electron count. The dense output path is
intended for small validation systems because it scales exponentially in the
number of spin orbitals.

Run `python examples/make_electronic_input.py` to create a small input under
the ignored `results/` directory.

## Algorithm profiles

### GPD

GPD retains the exact scalar candidate `K=0`, then follows the sequential,
non-fully-corrective source trajectory. Each new circuit is fitted to the
current full residual; earlier fragments remain fixed. The reference state is
not read during this process.

Calibrated GPD requires candidates `K=1,...,10`. After calibration, the
frontier terminates when no target-budget loss improves its running anchor by
more than `0.2%` for five consecutive post-calibration boundaries. Reaching
`max_terms` first is recorded as a right-censored, provisional selection.

The paper periodic-iSWAP matching is defined for even qubit counts. Odd counts
are rejected unless `odd_qubit_mode="open-chain"` (CLI:
`--odd-open-chain`) is explicitly requested and recorded as an extension.

iSWAP is a native two-qubit gate and is applied directly, without CNOT
synthesis. For even n and L entangling layers, each setting contains
3n(L+1) angles and nL/2 iSWAP gates at entangling depth L. At n=4, L=4 this
means 60 angles, 8 native iSWAP gates, depth 4, and zero CNOTs in the GPD
measurement ansatz. Preparation, single-qubit gates, routing and readout
are excluded from these entangling resources.

GPD results include `metadata["gate_resources_per_setting"]` and
`metadata["executed_gate_resources"]`. Executed counts use the actual integer
allocation and separate `cnot_gate_budget` and `iswap_gate_budget`;
`two_qubit_gate_budget` is their unweighted sum. A scalar-only result has
no executable setting and zero executed gates. Resource helpers are in
`src/mpqc_measurement/resources.py`; the legacy AGPD open-chain helper
retains its own matching pattern and is not the periodic GPD ansatz.

### SRDD

For electronic tensors, every positive rank is independently optimized at all
requested depths. Its depth is chosen first by the physical-particle-sector
Frobenius residual, with ties resolved toward the shallower circuit. The
selected source is then processed by:

1. joint shallow rotated-density tensor fitting;
2. the modified F3–R2 redistribution with full-Fock centered half-ranges;
3. a full-rank, greedy exact-fill, depth-matched one-body cover with at least
   one added shallow rotation; and
4. fixed-shot rank selection and integer allocation.

The electronic frontier includes the rank-zero one-body-only shallow cover.
Selecting the largest fitted positive rank is marked provisional so the rank
grid can be extended before drawing a convergence conclusion.

For a general dense or Pauli Hamiltonian without electronic tensors, SRDD uses
`H_parallel = 0` and a deterministic coefficient-sorted qubit-wise-commuting
Pauli residual completion. The result metadata identifies this backend; it is
not presented as an electronic tensor fit.

## Frozen balanced calibration

GPD and electronic SRDD use the same target-state-independent protocol:

- candidates `K=1,...,10` (`K=0` is selection-only);
- calibration budgets `100, 200, 300, 500, 800, 1200, 2000, 3000`;
- seed `918273`;
- grouped determinant and four-phase two-determinant stabilizer probes;
- equal weighting of eligible rank strata for approximation and eligible
  `(K,T_cal)` strata for sampling.

The four-qubit full-space catalog has 496 probes split `298/99/99`. The frozen
molecular catalog has 500 probes split `300/100/100`. Fitted weights are
independent of the requested target budget `T` and are stored in result
metadata. If a frontier does not contain all ten calibration candidates,
calibrated selection fails explicitly; use `calibrate=False` only when the
uncalibrated Frobenius-plus-range proxy is intended.

## Shot allocation and errors

For each nonconstant setting

```text
Q_i = U_i^dagger diag(d_i) U_i,
lambda_i = (max(d_i) - min(d_i)) / 2,
```

one shot is assigned first. Remaining shots are distributed in proportion to
`lambda_i` and integerized by the largest-remainder rule. Every strictly
positive half-range is active, and the returned allocation sums exactly to
`T`. A scalar-only or otherwise setting-free selected candidate uses zero
quantum shots and reports the budget as unused.

The returned approximation is

```text
H_hat = c I + sum_i Q_i.
```

Every result reports:

- `approximation_spectral_norm = ||H - H_hat||_2`;
- `approximation_frobenius_norm = ||H - H_hat||_F`;
- `sampling_variance_bound = sum_i lambda_i**2 / T_i`;
- the rigorous state-independent RMSE bound

```text
sqrt(||H - H_hat||_2**2 + sampling_variance_bound).
```

When frozen stabilizer calibration is enabled, `calibrated_proxy_rmse` is also
returned. It is an empirical model-selection proxy, not a rigorous bound.

With a reference state, the package additionally evaluates

```text
bias = <psi|(H_hat - H)|psi>
variance = sum_i Var_psi(Q_i) / T_i
state_rmse = sqrt(bias**2 + variance).
```

## Output

Each new output directory contains:

```text
result.json                 summary, configuration, hashes, and audit metadata
approximation.npz           H_hat, residual, integer shot vector
fragment_000.npz            unitary and computational-basis diagonal
fragment_001.npz
...
```

All NumPy inputs are loaded with `allow_pickle=False`. To prevent mixed or
stale runs, saving refuses an existing nonempty output directory. Result
metadata includes the package version and a SHA-256 fingerprint of the input
Hamiltonian, but not an absolute local input path.
